# Web de Febas Studio

Páginas públicas de las apps (privacidad, términos, borrar cuenta, soporte), servidas con GitHub Pages.

- Se generan con `python3 construir.py` (el correo y la fecha están arriba del archivo).
- `estilo.css` es común a todas.
- Englimals: `englimals/` (español) y `englimals/en/` (inglés).
